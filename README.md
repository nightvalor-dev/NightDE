NightDE

A portable, themeable dotfiles framework for Hyprland on Arch Linux — inspired by HyDE.

NightDE bundles an installer, curated Wayland-stack configs, and a wallpaper-driven theming pipeline into one opinionated but swappable setup for Hyprland.

Features
🖥️ One-command install — detects your system and sets up the full stack
🎨 Wallpaper-to-palette theming — colors are generated from your wallpaper and propagated across the bar, launcher, terminal, and notifications
🧩 Modular configs — drop any component without breaking the rest
📦 Layered package lists — base install plus optional extras
🔧 CLI wrapper — switch themes, change wallpapers, and reload configs from one command
Components
Component	Role
Hyprland	Wayland compositor
Waybar	Status bar
Rofi	App launcher / menu
Dunst / mako	Notifications
Kitty	Terminal emulator
SDDM	Login manager
Hyprlock / Hypridle	Lock screen / idle handling
